# 솔내마당 넘겨보기

PDF로 만든 학교 신문을 종이 신문처럼 넘겨 보는 웹페이지입니다. GitHub Pages로 배포합니다.

## 새 신문 올리기 (1년에 한 번)

1. `issues` 폴더에 PDF를 올립니다. 파일 이름은 영문·숫자로 합니다. (예: `issues/2027.pdf`)
2. `issues.js`를 열어 목록 **맨 위**에 한 줄을 추가합니다.

   ```js
   window.ISSUES = [
     { title: "2027년 제2호", file: "issues/2027.pdf" },
     { title: "2026년 창간호", file: "issues/2026.pdf" },
   ];
   ```

3. 저장(Commit)하면 1~2분 뒤 사이트에 반영됩니다.

맨 위에 적은 호가 처음 접속했을 때 열립니다. 목록이 비어 있으면 견본 신문이 보입니다.

## 참고

- PDF는 한 면이 한 쪽인 파일이어야 합니다. (두 면을 한 쪽에 붙인 펼침면 PDF는 쪽 단위로 나눠서 저장)
- GitHub 웹 화면에서 올릴 수 있는 파일은 25MB까지입니다. 더 크면 PDF 용량을 줄여서 올립니다.
- 주소 끝에 `#1`, `#2`처럼 번호를 붙이면 그 호가 바로 열립니다. (가장 오래된 호가 1번)
- 신문 이름과 학교 이름은 `issues.js`의 `window.SITE`에서 바꿉니다.
- 로고는 `img` 폴더에 있습니다. 어두운 배경용(흰색·연두색) 투명 PNG입니다.
- `lib` 폴더는 넘김 효과(StPageFlip)와 PDF 읽기(PDF.js) 도구입니다. 건드리지 않습니다.
